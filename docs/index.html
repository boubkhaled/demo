Document Structure

  • <!DOCTYPE> Defines document type
  • <html> Root element
  • <head> Contains metadata
  • <title> Page title
  • <body> Main content
  • <meta> Metadata about HTML
  • <link> External resources

Text Formatting

  • <h1>-<h6> Headings
  • <p> Paragraph
  • <strong> Important text
  • <em> Emphasized text
  • <mark> Highlighted text
  • <small> Smaller text
  • <blockquote> Long quotation

Links & Media

  • <a> Hyperlink
  • <img> Image
  • <video> Video player
  • <audio> Sound content
  • <source> Media resources
  • <figure> Self-contained content
  • <figcaption> Caption for figure

Complete HTML Tags Reference

Tag Description Example
<!DOCTYPE html> Defines the document type and HTML version <!DOCTYPE html>
<html> Root element of an HTML page <html lang="en">...</html>
<head> Container for metadata and page title <head><title>Page</title></head>
<title> Defines the title of the document <title>My Page</title>
<body> Contains the visible page content <body>Content here</body>
<h1> to <h6> Defines HTML headings <h1>Main Heading</h1>
<p> Defines a paragraph <p>This is a paragraph.</p>
<a> Defines a hyperlink <a href="url">Link</a>
<img> Embeds an image <img src="img.jpg" alt="description">
<div> Defines a division or section <div>Content section</div>
<span> Inline container for text <span>inline text</span>
<ul>, <ol>, <li> Defines unordered, ordered lists, and list items <ul><li>Item</li></ul>
<table>, <tr>, <td> Defines a table, table row, and table cell <table><tr><td>Data</td></tr></table>
<form> Defines an HTML form for user input <form action="/submit">...</form>
<input> Defines an input control <input type="text">
<button> Defines a clickable button <button>Click Me</button>
<header> Container for introductory content <header>Logo and nav</header>
<footer> Defines a footer for a document <footer>Copyright info</footer>
<section> Defines a section in a document <section>Content group</section>
<article> Defines independent, self-contained content <article>Blog post</article>
